# 从官方 PaddleOCR 独立编辑视觉骨干

## 给执行模型的任务

在 Windows 项目 `E:/impfile/imp/DeepLearning/exp3/ModelAdjust` 中，先检查实际代码、权重、数据和已有结果，再实现并运行本方案。研究问题是：仅用官方 OCR、原始训练裁图、人工转录和前向推理，能否定位一批会干扰学生答案识别的通道，通过直接修改一个卷积权重张量，提高全文识别和判题效果？

所有新代码和结果使用独立名称，新代码放在 `weight_editing/`，建议结果目录 `runs/direct-ocr-backbone-v1/`。本文路径均相对于 `ModelAdjust/`。已有目录若存在，先检查运行状态，按文件哈希恢复或使用新目录。保留原始权重、标签、已有实验和原实验报告正文。可以报告实验失败。

- **本轮新增证据必须独立构造。** 可以使用上一轮确定的模块位置。构造、选择或验证补丁的前向过程只加载 O0 和由它生成的候选。禁止读取 O1/O2/O3 张量、激活、预测、权重差分作为教师或目标。复用模型构建函数前检查其默认检查点，显式传入 O0 并核验哈希。
- **直接编辑组**全程使用 eval 模式、冻结 BN 和无梯度前向。禁止反向传播、优化器、有限差分估计梯度、用验证集或测试集求方向。可以用训练标签计算激活统计和前向干预效果。全程保存学生实际填写的数；算术判题器只计算评估指标。发现疑似错标，列出原图、现有标签和输出，保持原标注。

## 3. 从训练页提出可证伪的通道假设

**第一版假设**：对相似题目，官方模型读错手写答案时，某些通道的响应幅度会跨页稳定偏高或偏低。若这些差异参与造成错误，反向调整这些通道的贡献应比同幅随机干预修复更多题。仅有激活差异还不足以认定故障。

1. **错误组。** 只用发现页中标签和 O0 输出都恰有一个等号、题干规范化后完全相同、非空答案不同的裁图。漏字、多字、错字全部纳入，单独统计。**正确组**从相同发现页范围的原图中选取，要求全文正确且答案非空。学生答错算术但转录无误的样本同样属于正确组。
2. **匹配。** 每个错例最多配三张正确图，要求来自不同于错例的页、答案字符数相同、是否有小数点相同、首个答案字符相同。按裁图宽高比的对数差绝对值升序，再按裁图路径排序，同一错例的三个对照来自不同页。缺少对照的错例留在覆盖率分母中，记录原因。保存所有配对。至少有 30 个可配错例、覆盖 10 页才进入通道排名。
3. **取答案特征。** 用 O0 自己预测的等号 CTC 非空运行段的最后一步确定边界。依据实际骨干池化把后续有效时间步映射回压缩卷积输入的空间列，排除右侧 padding；用窄图、宽图和叠加到原图的样例核对映射。对这些列和全部高度求每个通道的平均绝对激活，得到每张图的 1,024 维向量。无可靠边界时只从方向估计中排除，不能从整体验证中排除。
4. **排名。** 每个错例的向量减去其匹配正确图的均值。同页错例先平均，再对页等权平均；每个通道除以发现页正确样本该通道的标准差，分母下限 `1e-6`，得到带符号分数 $s_j$。用种子 42 将参与估计的页打乱并平分，在两半分别重算分数。保留两半及总分符号一致、两半各至少有 5 个具有有效配对的错误页、且该通道在两半正确组中的标准差均大于 1e-6 的通道。按 $|s_j|$ 降序、通道编号升序，最多取 32 个。保存分数、编号、符号和有效样本数。若不足 8 个稳定通道，记录证据不足，结束本轮。

## 4. 先干预激活，再把同一操作写入权重

对选中的通道设置 (g_j=1-\alpha\,\mathrm{sign}$s_j$)，其余通道取 1。比较三个固定幅度 `α ∈ {0.10, 0.25, 0.50}`，种子 42。高响应通道受抑制、低响应通道被放大，这一方向假设由留出页检验。

| 组别 | 操作 | 要回答的问题 |
|---|---|---|
| O0 | 全部增益为 1 | 零干预能否复现官方输出？ |
| 定向组 | 按上述规则改选中通道 | 训练发现的通道是否有净收益？ |
| 随机组 | 固定随机抽相同数量的其他通道，打乱复用相同符号，统一缩放增量，使整个卷积的改变量 Frobenius 范数与定向组相等 | 随便改同等幅度能否得到相同收益？ |
| 反向组 | 在定向组的同一批通道上反转增量符号 | 实测效果是否支持假设的方向？ |

先用 hook 临时计算 `a[:, j, :, :] *= g[j]`。用于选模的干预必须作用于**整张图**，因为普通卷积权重在所有位置共享。可额外展示“仅答案区”的机制诊断数据，但不能把其收益计入最终模型。

对任意输入向量 $a$，压缩卷积满足 $W(g\odot a)=(W\,\mathrm{diag}(g))a$。因此直接在原始训练检查点的副本中写入：

```python
# NumPy float32，W.shape == (768, 1024, 1, 1)
W_edited = W * gains.reshape(1, 1024, 1, 1)
```

BN 参数和运行统计保留官方值，再用现有入口导出。推理时直接加载标准 `TextRecognition` 模型。不得依赖训练标签、位置掩码、教师或 hook。独立核验所有其他张量逐元素相同，并记录改动列、实际变动元素数和相对 Frobenius 范数。

## 5. 预算、选择与停止规则

1. **短流程。** 在包含长短图、错例及正确图的固定训练批次上检查零增量、输入坐标映射和干预方向。比较 hook 与写入权重后的同层输出、最终 logits 和逐题解码；记录最大绝对差和解码差异，FP32 先用 `atol=1e-4, rtol=1e-4`。导出后再用真实 `TextRecognition` 对照同一批次。无法解释的偏差先排查，不能靠换评估口径解决。
2. **训练内选幅度。** 所有组、所有幅度评估相同的 3,258 张训练留出图。定向组候选须全文净修复为正、超过同幅随机组和反向组，且相对 O0 的错题判对数不增加。合格者依次按全文正确数高、错题判对少、CER 低、幅度小选出唯一候选。若均不合格，保留 O0，可以按相同排序展示一个明确标注为诊断用的候选。此后锁定通道、方向、幅度与模型哈希。
3. **完整验证。** 正式推理评估 O0、锁定定向组及其同幅两种对照。正式接受要求定向组通过训练留出条件，并且相对 O0 全文正确数增加、CER 不升、错题判对数不增加。另列“原错减少率” (=(修复-退步)/O0全文错题数)。验证集约定以 30% 作为“大幅收益”的描述门槛，与模型接受条件分开。验证后不能重新换通道或调幅度。
4. **最终测试。** 写出选择锁后，再跑 2,767 张测试裁图及同一批 88 页整页测试。沿用现有 Y2 检测框、裁图规则及 IoU 0.50。未获接受的定向组可与两种对照一起作为锁定的诊断模型测试，但推荐模型仍为 O0。明确结果属于已分析测试集上的单种子后续探索。
5. **和传统微调比较。** 单列同一测试裁图的历史 200 步全量微调、历史 O3、以及前一轮 384 权重的直接编辑结果，注明数据、预算和选模差异。只对当前同起点的定向、随机、反向组作方向归因。已有 O3 模块交换净修复 91 题的数字只用于解释选层，不能列为本方法的成绩。
